# mcuelenaere/homebrew-tap

```sh
brew install --cask mcuelenaere/tap/regi
```

[Regi](https://github.com/mcuelenaere/regi) is a macOS client for JetKVM, PiKVM and VNC KVM-over-IP devices.

`Casks/regi.rb` is bumped automatically by Regi's release workflow. Until the first tagged release its `sha256` is a placeholder, so installs fail the checksum check until then.
